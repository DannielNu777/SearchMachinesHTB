# SearchMachinesHTB

Herramienta versátil en Bash perfecta para buscar máquinas realizadas en Hack the Box por S4vitar streamer y Youtuber Español. 

Esta utilidad nos permitirá listar y buscar máquinas principalmente por:

  u)  Descargar o actualizar los archivos necesarios
	i)  Buscar por direccion IP 
	m)  Buscar por nombre de la màquina
	y)  Buscar por link de Youtube
	d)  Buscar por dificultad de la màquina
	o)  Buscar por el sistema operativo
	h)  Mostrar el panel de ayuda para el usuario
